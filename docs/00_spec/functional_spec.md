# IkTerminal 機能仕様

軽量・省メモリを最優先とした Windows 向けタブ型ターミナル。ローカルシェル、SSH 接続、SFTP ファイル転送、OpenSSH config の編集を 1 つの実行ファイルで提供する。

## 1. 画面構成

| 領域 | 内容 |
| --- | --- |
| タブバー | サイドバー切替、タブ (状態ドット / 閉じる)、新規タブ、SFTP パネル切替、設定 |
| サイドバー | ローカルシェル一覧、SSH ホスト一覧、クイック接続、ホスト検索、config 編集 / 再読込 |
| ターミナル | アクティブタブの端末画面。接続中・エラー時は上部にバナーを表示 |
| SFTP パネル | SSH タブでのみ有効。リモートのファイル一覧と転送状況 |

タブがない場合はウェルカム画面 (ローカルシェルを開く / SSH config を編集) を表示する。

## 2. ターミナル

- xterm-256color 互換 (alacritty_terminal)。TrueColor、太字・下線・取消線・反転、代替スクリーン、ブラケットペースト、マウスレポート (SGR / X10) に対応する。
- 日本語 (全角文字) 表示と IME 入力 (変換中文字列のインライン表示) に対応する。
- スクロールバック行数は設定で変更できる (既定 5000)。
- 選択: ドラッグで範囲選択、ダブルクリックで単語、トリプルクリックで行。
- コピー / 貼り付け
  - Ctrl+C: 選択があればコピー、なければ ^C を送信。
  - Ctrl+V: 貼り付け。
  - 右クリック: 選択があればコピー、なければ貼り付け。
- Ctrl+ホイールでフォントサイズを変更 (8 - 32pt) し、設定に保存する。
- ファイルをドロップすると、そのパスを入力する。SFTP パネルが開いていて接続済みの場合はアップロードする。

## 3. ローカルシェル

- 自動検出: PowerShell 7 (pwsh)、Windows PowerShell、コマンド プロンプト、WSL。
- 設定で既定シェルを選択するか、任意のコマンドラインを指定できる。
- 作業ディレクトリはホームディレクトリ。シェルが終了するとタブを閉じる。

## 4. SSH

### 4.1 OpenSSH config の読み込み

- `~/.ssh/config` を読み込み、`Host` のエイリアス (ワイルドカードを含まないもの) をサイドバーに一覧表示する。
- 対応キーワード: `Host` (`!` による否定を含む)、`Match all`、`Include` (glob 可)、`HostName`、`User`、`Port`、`IdentityFile`、`IdentitiesOnly`、`ProxyJump`、`ServerAliveInterval`、`ConnectTimeout`。
- `Match all` 以外の `Match` 条件は評価せず、一致しないものとして扱う。
- 値は最初に得られたものを採用する。`IdentityFile` のみ累積する。トークン `%d %u %h %r` と `~` を展開する。
- クイック接続欄には `[user@]host[:port]` を入力できる。config に一致するエイリアスがあれば、その設定を適用する。

### 4.2 接続と認証

- ホスト鍵は `~/.ssh/known_hosts` で検証する。
  - 未登録の場合はフィンガープリントを表示して確認し、承認されたら登録する。
  - 鍵が変更されている場合は接続を拒否する。
- 認証は次の順で試行する。
  1. SSH エージェント (OpenSSH エージェント、Pageant)。`IdentitiesOnly yes` の場合は使わない。
  2. 鍵ファイル (`IdentityFile`、未指定時は `id_ed25519`、`id_ecdsa`、`id_rsa`)。暗号化鍵はパスフレーズを入力する。
  3. keyboard-interactive。
  4. パスワード (最大 3 回)。
- `ProxyJump` (多段) に対応する。
- 接続タイムアウトは `ConnectTimeout` (既定 15 秒)。対象は TCP 接続の確立 (踏み台経由の場合はトンネル開設) のみで、ユーザーの応答待ちは含まない。
- 切断またはエラーの際は、バナーに理由と「再接続」「閉じる」を表示する。

## 5. SFTP

- SSH タブで SFTP パネルを開くと、同じ SSH 接続上で SFTP セッションを開始する。
- 操作
  - ディレクトリ移動: ダブルクリック、上へ、パス直接入力。
  - 更新。
  - 新規フォルダ。
  - 名前変更。
  - 削除: フォルダは中身ごと削除する。
- アップロード: ファイル選択ダイアログ、またはドラッグ & ドロップ。フォルダは再帰的に転送する。
- ダウンロード: ファイルはダブルクリックまたはコンテキストメニューで行う。保存先フォルダを選択する。フォルダは再帰的に転送する。
- 転送一覧に進捗バーを表示する。転送は中止できる。完了したものは一覧から消去できる。

## 6. OpenSSH config 編集

- 「SSH config の編集」ウィンドウで `~/.ssh/config` を編集する。
- フォームモード
  - ブロック (共通設定 / Host / Match) を一覧から選択する。
  - 主要項目 (HostName、User、Port、IdentityFile、ProxyJump) を編集する。IdentityFile はファイル選択ダイアログで指定できる。
  - その他のオプションをキーと値で編集・追加・削除する。
  - ホストを追加 (`Host *` より前に挿入) / 削除する。
- テキストモード: ファイル全体をそのまま編集する。
- フォームでの編集は、コメントや未知のオプション、インデントを保持したまま書き戻す。
- 保存時は既存ファイルを `config.bak` に退避してから書き込み、ホスト一覧を再読込する。

## 7. 設定

- 項目: フォントサイズ、フォントファイル (空なら自動選択)、既定シェル、スクロールバック行数。
- 保存先: `%APPDATA%\IkTerminal\settings.conf` (`key=value` 形式)。

## 8. キーボードショートカット

| キー | 動作 |
| --- | --- |
| Ctrl+Shift+T | 新規タブ (既定シェル) |
| Ctrl+Shift+W | タブを閉じる |
| Ctrl+Tab / Ctrl+Shift+Tab | 次 / 前のタブ |

## 9. 配布

- 単一の実行ファイル (アイコン埋め込み) として配布する。
- Inno Setup 6 による Windows インストーラを提供する。
  - ユーザー単位 / 全ユーザーのどちらでもインストールできる。
  - スタートメニューに登録する。デスクトップアイコンは任意。
  - アンインストーラを含む。

## 10. 非機能要件

- メモリ使用量: アプリ自身が消費するメモリを最小にする。
  - レンダラは OpenGL (Glow) を使う。wgpu は使わない。
  - フォントはシステムフォントをメモリマップで共有する。
  - 非同期処理は 2 スレッドのランタイムで行う。
- 実行ファイルサイズを最小にする: サイズ最適化、LTO、strip。
- ビルド時の警告ゼロを維持する (clippy を含む)。
