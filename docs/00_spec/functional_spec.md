# IkTerminal 機能仕様

軽量・省メモリを最優先としたタブ型ターミナル (Windows / Linux)。ローカルシェル、SSH 接続、SFTP ファイル転送、OpenSSH config の編集を 1 つの実行ファイルで提供する。

## 1. 画面構成

| 領域 | 内容 |
| --- | --- |
| タブバー | サイドバー切替、タブ (状態ドット / 閉じる)、新規タブ、SFTP パネル切替、設定、最小化 / 最大化 / 閉じる |
| サイドバー | ローカルシェル一覧、SSH ホスト一覧、クイック接続、ホスト検索、config 編集 / 再読込 |
| ターミナル | アクティブタブの端末画面。接続中・エラー時は上部にバナーを表示 |
| SFTP パネル | SSH タブでのみ有効。リモートのファイル一覧と転送状況 |

タブがない場合はウェルカム画面 (ローカルシェルを開く / SSH config を編集) を表示する。サイドバーは起動時は閉じている。

設定「タスクトレイ」が有効なとき、ウィンドウを閉じてもプロセスは終了せず、タスクトレイに残る。アイコンの左クリック、またはメニューの「表示」でウィンドウを戻す。メニューの「終了」で終了する。無効のときはアイコンを出さず、閉じると終了する。既定は無効。

OS のタイトルバーは出さない。タブバーの空きをドラッグするとウィンドウが移動し、ダブルクリックで最大化する。端と角のドラッグでサイズを変える。タブが 1 つのときは、そのタブをドラッグしてもウィンドウが移動する。タブが 2 つ以上あるときは、タブを左右にドラッグすると並び順が変わる。ウィンドウの外までドラッグすると、そのタブだけの新しいウィンドウが開く。

`+` と Ctrl+Shift+T はメニューを開き、ローカルシェル (PowerShell、コマンド プロンプト、WSL など)、シリアル (COM)、または SSH ホストを選んでタブを開く。

## 2. ターミナル

- xterm-256color 互換 (alacritty_terminal)。TrueColor、太字・下線・取消線・反転、代替スクリーン、ブラケットペースト、マウスレポート (SGR / X10) に対応する。
- 日本語 (全角文字) 表示と IME 入力 (変換中文字列のインライン表示) に対応する。
- スクロールバック行数は設定で変更できる (既定 5000)。
- 選択: ドラッグで範囲選択、ダブルクリックで単語、トリプルクリックで行。
- コピー / 貼り付け
  - Ctrl+C: 選択があればコピー、なければ ^C を送信。
  - Ctrl+V: 貼り付け。
  - 右クリック: 選択があればコピー、なければ貼り付け。
- Ctrl+ホイールでフォントサイズを変更 (8 - 32pt) し、設定に保存する。
- ファイルをドロップすると、そのパスを入力する。SFTP パネルが開いていて接続済みの場合はアップロードする。

## 3. ローカルシェル

- Windows の自動検出: PowerShell 7 (pwsh)、Windows PowerShell、コマンド プロンプト、WSL。
- Linux の自動検出: `$SHELL`、PATH 上の bash / zsh / fish、`/bin/sh`。同じ実行ファイルは 1 回だけ載せる。
- 設定で既定シェルを選択するか、任意のコマンドラインを指定できる。
- 作業ディレクトリは、起動引数で指定したフォルダ。引数がなければホームディレクトリ。同じウィンドウで開くローカルタブは同じフォルダを使う。
- 起動引数は `ikt [フォルダ]`。`.` はそのプロセスのカレントフォルダ (エクスプローラーのアドレスバーで `ikt .` と打ったとき、表示中のフォルダになる)。
- すでに起動しているときは、新しいプロセスはウィンドウを開かず終了する。フォーカスのあるウィンドウ (無ければ最初のウィンドウ) にローカルタブを追加し、そのウィンドウを前面に出す。追加したフォルダが、その後そのウィンドウで開くローカルタブの作業ディレクトリになる。
- シェルが終了するとタブを閉じる。
- ローカルタブは `フォルダ · シェル名` と表示する。フォルダはシェルプロセスの作業ディレクトリの末尾で、`cd` すると追従する。マウスオーバーでフルパスを表示する。ウィンドウタイトルも同じ表記にする。WSL は起動時の Windows 側フォルダのままである。

## 4. SSH

### 4.1 OpenSSH config の読み込み

- `~/.ssh/config` を読み込み、`Host` のエイリアス (ワイルドカードを含まないもの) をサイドバーに一覧表示する。
- 対応キーワード: `Host` (`!` による否定を含む)、`Match all`、`Include` (glob 可)、`HostName`、`User`、`Port`、`IdentityFile`、`IdentitiesOnly`、`ProxyJump`、`ServerAliveInterval`、`ConnectTimeout`。
- `Match all` 以外の `Match` 条件は評価せず、一致しないものとして扱う。
- 値は最初に得られたものを採用する。`IdentityFile` のみ累積する。トークン `%d %u %h %r` と `~` を展開する。
- クイック接続欄には `[user@]host[:port]` を入力できる。config に一致するエイリアスがあれば、その設定を適用する。

### 4.2 接続と認証

- ホスト鍵は `~/.ssh/known_hosts` で検証する。
  - 未登録の場合はフィンガープリントを表示して確認し、承認されたら登録する。
  - 鍵が変更されている場合は接続を拒否する。
- 設定「Bitwarden」が有効 (既定) で Bitwarden がインストール済みかつ未起動のとき、認証の前にデスクトップアプリを起動し、エージェントの名前付きパイプが出るまで少し待つ。インストーラ版は `Bitwarden.exe`、Microsoft Store 版は登録されたアプリ ID で起動する。どちらも無い場合は何もしない。Windows ではエージェントは `\\.\pipe\openssh-ssh-agent` を使うため、OpenSSH Authentication Agent サービスは無効にしておく。
- 認証は次の順で試行する。
  1. SSH エージェント (OpenSSH エージェント、Bitwarden のエージェント、Pageant)。`IdentitiesOnly yes` の場合は使わない。
  2. 鍵ファイル (`IdentityFile`、未指定時は `id_ed25519`、`id_ecdsa`、`id_rsa`)。暗号化鍵はパスフレーズを入力する。
  3. keyboard-interactive。
  4. パスワード (最大 3 回)。
- `ProxyJump` (多段) に対応する。
- 接続タイムアウトは `ConnectTimeout` (既定 15 秒)。対象は TCP 接続の確立 (踏み台経由の場合はトンネル開設) のみで、ユーザーの応答待ちは含まない。
- 切断またはエラーの際は、バナーに理由と「再接続」「閉じる」を表示する。

### 4.3 コマンドからの config 追加

- ローカルシェルまたは SSH セッションで Enter した行に `ssh` コマンドがあると、`~/.ssh/config` に追加するか尋ねる。
- プロンプト (`PS C:\>` や `user@host:~$`) の後ろ、または `&&` などで始まるコマンドだけを見る。`echo ssh` や `ssh-keygen` は対象外。
- 取り込む項目: 接続先、ユーザー (`user@` または `-l`)、ポート (`-p`)、秘密鍵 (`-i`)、踏み台 (`-J`)、`-o` の HostName / User / Port / IdentityFile / ProxyJump。
- 同じ接続先が config に既にある場合、またはこのウィンドウで追加を断った場合は、再度尋ねない。
- ダイアログでエイリアスなどを直してから保存できる。保存時は既存ファイルを `config.bak` に退避する。

### 4.4 Cursor で開く

- SSH セッションで `cursor`、`cursor .`、`cursor <パス>` を Enter すると、その行はリモートでは実行しない。
- ローカルの Cursor を起動し、Remote-SSH でそのフォルダを開く。URI は `vscode-remote://ssh-remote+<ホスト><絶対パス>`。
- ホストは `~/.ssh/config` のエイリアスを優先する。エイリアスが無いときは、入力した `user@host` か `user@host:port` を使う。ポート、ユーザー、鍵、ProxyJump は config の定義に従う。
- パスが `.` または相対パスのとき、カレントフォルダは次の順で決める。
  1. プロンプト、その直前の行、ウィンドウタイトルに含まれるパス。
  2. OSC 7、OSC 9;9、OSC 1337 の `CurrentDir`。
  3. 入力した `cd`。
  4. 接続直後の作業ディレクトリ。
- それでも決まらないときは、シェルに作業ディレクトリとホームを一度問い合わせる。
- `cursor` 以外のコマンドと混ぜた行、代替スクリーン、接続中でないときは対象外。Cursor が無いときはその旨を表示する。

## 5. シリアル (COM)

- `+` メニューの「シリアル (COM)」からポートとボーレートを選んで接続する。
- データ形式は 8 ビット、パリティなし、ストップビット 1、フロー制御なし。
- ボーレート: 9600、19200、38400、57600、115200 (既定)、230400、460800、921600。
- 切断時は理由を表示し、再接続またはタブを閉じる。

## 6. SFTP

- SSH タブで SFTP パネルを開くと、同じ SSH 接続上で SFTP セッションを開始する。
- 操作
  - ディレクトリ移動: ダブルクリック、上へ、パス直接入力。
  - 更新。
  - 新規フォルダ。
  - 名前変更。
  - 削除: フォルダは中身ごと削除する。
- アップロード: ファイル選択ダイアログ、またはドラッグ & ドロップ。フォルダは再帰的に転送する。
- ダウンロード: ファイルはダブルクリックまたはコンテキストメニューで行う。保存先フォルダを選択する。フォルダは再帰的に転送する。
- 転送一覧に進捗バーを表示する。転送は中止できる。完了したものは一覧から消去できる。

## 7. OpenSSH config 編集

- 「SSH config の編集」ウィンドウで `~/.ssh/config` を編集する。
- フォームモード
  - ブロック (共通設定 / Host / Match) を一覧から選択する。
  - 主要項目 (HostName、User、Port、IdentityFile、ProxyJump) を編集する。IdentityFile はファイル選択ダイアログで指定できる。
  - その他のオプションをキーと値で編集・追加・削除する。
  - ホストを追加 (`Host *` より前に挿入) / 削除する。
- テキストモード: ファイル全体をそのまま編集する。
- フォームでの編集は、コメントや未知のオプション、インデントを保持したまま書き戻す。
- 保存時は既存ファイルを `config.bak` に退避してから書き込み、ホスト一覧を再読込する。

## 8. 設定

- 項目: フォントサイズ、フォントファイル (空なら自動選択)、既定シェル、スクロールバック行数、SSH 開始時に Bitwarden を起動するか、タスクトレイに常駐するか (既定はしない)。実行中のバージョンと「更新を確認」も出す。
- 保存先 (`key=value` 形式)
  - Windows: `%APPDATA%\IkTerminal\settings.conf`
  - Linux: `$XDG_CONFIG_HOME/IkTerminal/settings.conf`。未設定なら `~/.config/IkTerminal/settings.conf`

## 9. キーボードショートカット

| キー | 動作 |
| --- | --- |
| Ctrl+Shift+T | 新規タブのメニュー (ローカルシェル、シリアル、SSH ホスト) |
| Ctrl+Shift+W | タブを閉じる |
| Ctrl+Tab / Ctrl+Shift+Tab | 次 / 前のタブ |

## 10. 配布

バージョンの正は `Cargo.toml` の `version` だけとする。Windows のファイルバージョン、インストーラ名、Linux アーカイブ名、Git タグ `v<version>` はすべてこれを参照する。

- Windows
  - 単一の実行ファイル (アイコンとバージョンリソースを埋め込む)。同じ内容の `ikt.exe` を同梱する。
  - Inno Setup 6 によるインストーラ `IkTerminal-<version>-setup.exe`。
    - ユーザー単位 / 全ユーザーのどちらでもインストールできる。
    - スタートメニューに登録する。デスクトップアイコンは任意。
    - アンインストーラを含む。
    - インストール先をユーザーの PATH に加え、`ikt.exe` を App Paths に登録する。エクスプローラーのアドレスバーで `ikt .` とすると、そのフォルダのタブを開く。起動中なら既存のウィンドウに追加する。
- Linux
  - 単一バイナリを `IkTerminal-<version>-linux-<arch>.tar.gz` で配布する。
  - 実行時に libxcb、libxkbcommon、libxkbcommon-x11、OpenGL が必要。
  - クリップボードは X11 と Wayland。ファイル選択は xdg-desktop-portal。
  - 日本語表示には Noto Sans CJK などのシステムフォントを使う。
- CI
  - push と pull request で Windows と Linux を検査し、上記の配布物を作る。
  - `main` へ push したとき、`version` が直前の `main` と異なり、タグ `v<version>` が無ければそのタグと GitHub Release を作る。同じコミットの再実行、または手動実行でも、タグが無ければ Release を作る。

リリースビルドは起動後に GitHub の最新リリースを確認する。設定の「更新を確認」でも同じ確認をすぐ行う。実行中より新しいバージョンで、対象の配布物の SHA-256 が Release の `digest` と一致するとき、画面に `Ver.Up` を出す。押すと更新して終了する。「今はしない」を選ぶとその起動では更新しない。終了しただけでは更新しない。設定では、最新なら「最新です」、新しい版なら「Ver.Up で更新します」、確認できないときは「確認できませんでした」と出す。ウィンドウを隠しているときは、タスクトレイのツールチップにも新しいバージョンを出す。

- Windows は `IkTerminal-<version>-setup.exe` をサイレント実行し、今のインストール先を更新してからアプリを起動する。インストール先に書き込めないときは昇格を求める。
- Linux は `IkTerminal-<version>-linux-<arch>.tar.gz` の `ikterminal` で、今の実行ファイルを置き換える。

デバッグビルドは確認しない。設定から押したときは「デバッグビルドでは確認しません」と出す。起動時の確認で、ネットワーク障害、Release が無い、digest が無い、ハッシュが一致しないときは何も出さない。設定からの確認では「確認できませんでした」と出す。

## 11. 非機能要件

- メモリ使用量: アプリ自身が消費するメモリを最小にする。
  - レンダラは OpenGL (Glow) を使う。wgpu は使わない。
  - フォントはシステムフォントをメモリマップで共有する。
  - 非同期処理は 2 スレッドのランタイムで行う。
- 実行ファイルサイズを最小にする: サイズ最適化、LTO、strip。
- ビルド時の警告ゼロを維持する (clippy を含む)。
